# Easter-Bunny-Tracker
This tracker is a Flask-based web application that simulates the magical journey of the Easter Bunny around the City of South Charleston, West Virginia. Designed with simplicity and holiday spirit in mind, the site offers an engaging experience for kids and families who want to follow the Easter Bunny throughout the city! Built with Python, Flask, and Bootstrap, it features live-tracking via Traccar, tracking animations, and a mobile-friendly interface.

🛠️ Technologies Used: Python, Flask, Bootstrap
🌍 Features: Real-time updates, mobile responsive, themed design
🐣 Perfect for: Families, classrooms, and holiday events
